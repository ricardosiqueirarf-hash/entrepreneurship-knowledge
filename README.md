# Knowledge Base — Empreendedorismo, Economia e Gestão

Um repositório pessoal para organizar **o que estudo, o que compreendo, o que penso e o que consigo aplicar** em problemas reais de negócios.

A proposta não é criar um curso ou uma enciclopédia. É construir um **portfólio intelectual versionado**: ideias rastreáveis, argumentos explícitos, referências, exemplos e revisões ao longo do tempo.

**Áreas de interesse:** economia, contabilidade, finanças, vendas, estratégia, custos, logística e gestão.

## Como ler o conteúdo

Cada publicação deve deixar claro o que é:

- **Conhecimento estabelecido:** conceitos fundamentados em fontes identificáveis.
- **Interpretação pessoal:** minha leitura ou síntese dos conceitos.
- **Hipótese:** uma proposição ainda não testada ou insuficientemente demonstrada.
- **Aplicação:** uma decisão, experimento ou caso concreto e seus limites.

## Histórico e transparência

O Git registra as mudanças. Uma atualização pode corrigir erros, adicionar evidências, ampliar exemplos ou registrar uma mudança de opinião. A versão atual não apaga a trajetória de aprendizagem.

> **Status:** estrutura inicial. Os textos de exemplo não devem ser interpretados automaticamente como opiniões pessoais consolidadas.

## Organização

As notas são escritas em Markdown para permitir edição simples, links entre conceitos e, futuramente, publicação em um site próprio.
