# Princípios

Aqui ficam as convicções e os critérios que orientam decisões empresariais.

Cada princípio deverá apresentar:

1. **Enunciado:** a ideia em uma frase.
2. **Justificativa:** por que acredito nela.
3. **Fundamentação:** teorias, evidências e autores relevantes.
4. **Contrapontos:** objeções e interpretações concorrentes.
5. **Aplicações:** decisões práticas em que o princípio foi útil.
6. **Condições de revisão:** o que poderia me fazer mudar de opinião.

> Esta seção começa sem teses pessoais preenchidas. Convicções só devem ser publicadas após formulação e revisão explícitas.
