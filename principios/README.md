# Princípios

Este espaço reúne **princípios que considero importantes** e os argumentos que os sustentam.

Cada princípio pode conter:
- **Enunciado:** a ideia central.
- **Justificativa:** por que a defendo.
- **Fundamentação:** evidências, autores ou teorias relevantes.
- **Contrapontos:** objeções e condições em que o princípio pode não se aplicar.
- **Revisões:** como meu entendimento mudou ao longo do tempo.

> Nenhum princípio pessoal foi atribuído automaticamente. Esta seção está pronta para receber minhas formulações.
