# Aplicações práticas

Esta seção reunirá casos em que conceitos de gestão, economia e finanças foram usados para analisar decisões reais.

## Estrutura sugerida para cada caso

- **Contexto:** setor, porte e problema, sem expor dados confidenciais.
- **Decisão:** o que foi alterado e por quê.
- **Conhecimentos envolvidos:** links para as notas conceituais.
- **Método:** cálculos, premissas e alternativas consideradas.
- **Resultados:** métricas, período e qualidade dos dados.
- **Limitações:** fatores externos, incertezas e possíveis explicações alternativas.
- **Aprendizado:** o que manteria ou mudaria.

> Não publicar dados comerciais, informações de clientes ou números sensíveis sem autorização.
